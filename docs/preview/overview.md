# Preview

The Preview panel lets you inspect search results without leaving Glimpse.

When you select a search result, the Preview updates automatically. You do not need to press `Enter` to inspect a file.

## Live Preview

```text
Search Results       Live Preview

Rust          ->      Rust.md
Markdown      ->      Markdown.md
Commands      ->      Commands.md
```

The Live Preview follows the currently selected result.

## Preview Tabs

Press `Ctrl + T` to keep the current Preview open as a Preview Tab.

Preview Tabs remain open while you continue searching.

## Preview Types

Glimpse can preview several item types:

| Type               | Behavior                                    |
| ------------------ | ------------------------------------------- |
| Markdown           | Renders Markdown content                    |
| Raw                | Shows original text without rendering       |
| External           | Shows URL-based preview when available      |
| Image              | Shows supported image files                 |
| Metadata-only file | Shows a lightweight file reference          |
| Plugin viewer      | Lets trusted plugins render supported files |
| Internal Page      | Shows built-in app pages and plugin pages   |

## Internal Pages

Internal Pages such as Settings, Shortcuts, About, Debug, Command History, Plugin Page, and trusted plugin pages are displayed in the Preview panel like normal items.

## Shortcuts

Preview shortcuts can be viewed or customized in **Settings -> Shortcuts**.
