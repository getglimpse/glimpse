# Glimpseとは？

Glimpse は、高速なローカル検索ランチャーです。

Markdown ファイル、Glimpse JSON インデックス (`.gjson`)、コマンド、内部ページなどを単一の検索バーから検索し、必要な情報へ素早くアクセスできます。

Glimpse は、大規模な知識管理システムを目指したアプリではありません。
あとで見返したいメモや、よく使うコマンド、調べたこと、作業用ドキュメントなどを、できるだけ少ない操作で見つけられることを重視しています。

## 主な特徴

### 高速なインクリメンタル検索

入力に応じて検索結果をリアルタイムに更新します。

Markdown ファイルや `.gjson` インデックス、内部ページ、コマンドなどを横断して検索できます。

検索では、タイトルや本文に加え、Metadata によるタイトル・タグ・エイリアスなども利用できます。

数千〜数万件のアイテムが存在する場合でも、目的の情報へ素早くアクセスできます。

### Preview

検索結果をアプリ内でプレビューできます。

Markdown プレビューでは、以下の要素に対応しています。

* 見出し
* リスト
* テーブル
* コードブロック
* インラインコード
* 画像
* 引用

外部エディタを開くことなく、検索結果の内容をすぐに確認できます。

### Preview Tabs

複数の検索結果をタブとして保持できます。

例えば、

* API リファレンス
* 作業メモ
* TODO
* コマンド一覧

などを同時に開き、タブを切り替えながら作業できます。

### Metadata

Markdown の Frontmatter を利用して検索情報を追加できます。

```yaml
---
title: Rust

tags:
  - rust
  - programming

aliases:
  - r
---

# Rust
```

タイトル、タグ、エイリアスなどを設定することで、目的のドキュメントを見つけやすくできます。

### Glimpse JSON Index

`.gjson` ファイルから検索項目を追加できます。

ブックマーク集やコマンド一覧、社内ドキュメントなどを一括で管理し、Markdown ファイルと同じように検索できます。

### Command Launcher

検索バーから組み込みページや信頼済みプラグインページを検索できます。

```text
:settings

:about

:plugin
```

設定画面やプラグイン管理などのアプリ内ページを、キーボードだけで開けます。コマンドランチャー item やプラグインの page action は、`>` を使って引数も受け取れます。

### Real-time Indexing

監視対象フォルダをリアルタイムで監視します。

以下の変更は自動的に検索インデックスへ反映されます。

* ファイルの作成
* ファイルの更新
* ファイルのリネーム
* ファイルの削除

通常、手動で再インデックスを実行する必要はありません。

## Glimpse が向いている人

Glimpse は、次のような用途に向いています。

* Markdown メモを大量に管理している
* Obsidian の Vault を高速に検索したい
* 作業メモをすぐ開きたい
* キーボード中心で作業したい
* よく使うコマンドをランチャーとして利用したい

## Glimpse の考え方

Glimpse は、必要な情報へ素早くアクセスできることを重視しています。

複雑な機能や設定を増やすのではなく、検索して確認し、必要に応じて開くという操作をできるだけ短時間で行えるよう設計しています。
