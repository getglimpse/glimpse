## Glimpse について

Glimpse は、ローカルにある知識へすばやくアクセスするためのデスクトップランチャーです。

Markdown ノート、`.gjson` インデックス、画像、Raw file、Internal Pages、信頼済みプラグインのページやアクションを同じ検索ワークフローで扱えます。

現在は beta 版です。基本的な検索とプレビューは利用できますが、一部の仕様やプラグイン API は今後変更される可能性があります。
