# Settings Page

Settings Page では、Glimpse 全体の動作や表示方法を変更できます。

## 外観

アプリケーションの見た目を変更します。

### Theme

テーマを切り替えられます。

* Built-in Themes
* Custom Themes

カスタムテーマは CSS ファイルとして管理されており、「テーマフォルダを開く」 をクリックするとテーマフォルダを開けます。

このフォルダへ `.css` ファイルを配置すると、テーマ一覧へ自動的に追加されます。

## ターゲットグループ

検索対象となるディレクトリを管理します。

ターゲットグループを追加・削除できます。各ターゲットグループには複数のディレクトリを登録できます。
通常検索で使用するターゲットグループは、デフォルトの場合 `Ctrl` + `R` を押して切り替えられます。

## UI

ユーザーインターフェースに関する設定です。

### Compact List

検索結果をコンパクト表示します。

### Language

表示言語を変更します。

対応言語：

* 日本語
* English

## セキュリティ

Command Launcher の実行ルールを設定します。

### Command Policy

コマンドの実行可否を判定する方法を選択します。

* None
* Whitelist
* Blacklist

### Allowed Commands

Whitelist モードで実行を許可するコマンドを管理します。

### Blocked Commands

Blacklist モードで実行を禁止するコマンドを管理します。

## 実験的機能

OS やアプリケーション固有の挙動に依存する機能を試せます。

### 選択テキストをクエリに使う

有効にすると、グローバルショートカットで Glimpse のメインウィンドウを開くときに、前面アプリで選択されているテキストの読み取りを試みます。

テキストを読み取れた場合、そのテキストが検索欄の query になります。読み取れない場合は、現在の query を維持したまま通常どおり開きます。

前面アプリの Windows UI Automation 対応状況に依存するため、この設定はデフォルトでは無効です。

## 詳細設定

高度な設定を管理します。

### Settings File

設定ファイルを直接開いて編集できます。

通常は設定画面から変更することを推奨します。
