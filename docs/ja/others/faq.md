# FAQ

よくある質問と回答をまとめています。

## Search

### 検索結果にファイルが表示されません

次の点を確認してください。

* 対象フォルダが Target Groups に登録されている
* インデックスの作成が完了している
* ファイルが検索対象になっている

改善しない場合は **Full Scan** を実行してください。

### ファイルを更新したのに検索結果が変わりません

通常は変更が自動的に反映されます。
反映されない場合は、数秒待ってから **Full Scan** を実行してください。

### 検索順位を変更できますか？

はい。
Metadata を利用すると検索順位を調整できます。
詳しくは **Metadata** のページを参照してください。

## Preview

### Preview を固定できますか？

はい。
**Ctrl + T** を押すと、現在の Preview を Preview Tab に追加できます。

### Preview Tabs は複数開けますか？

はい。
複数の Preview Tabs を同時に開き、切り替えながら利用できます。

### Markdown が正しく表示されません

Markdown の記法を確認してください。
対応していない拡張記法は、そのままテキストとして表示される場合があります。

## Metadata

### Metadata は必須ですか？

いいえ。
Metadata がなくても検索や Preview は利用できます。

### aliases や tags は何に使いますか？

検索しやすくするための情報です。
詳しくは **Metadata** のページを参照してください。

### Metadata を変更したら再起動は必要ですか？

いいえ。
保存すると自動的にインデックスが更新されます。

## Target Groups

### 新しいフォルダを追加するには？

Settings の **Target Groups** から追加できます。

### フォルダを削除すると元のファイルも削除されますか？

いいえ。
削除されるのは検索インデックスのみで、元のファイルは削除されません。

## Settings

### テーマを変更できますか？

はい。
Settings の **Theme** から変更できます。

### カスタムテーマを追加するには？

Settings の **「テーマフォルダを開く」** をクリックし、テーマフォルダへ `.css` ファイルを配置してください。
配置したテーマはテーマ一覧から選択できます。

### 表示言語を変更できますか？

はい。Settings の **Language** から変更できます。

## Security

### Command が実行できません

Security の設定を確認してください。Whitelist または Blacklist を利用している場合は、実行するコマンドが許可されている必要があります。

## Troubleshooting

### 検索結果がおかしい場合はどうすればよいですか？

次の順番で確認してください。

1. **Full Scan** を実行する
2. Target Groups を確認する
3. Glimpse を再起動する

### アプリの動作が遅いです

初回のインデックス作成中は時間がかかる場合があります。初回完了後は、変更されたファイルのみが更新されるため、通常は高速に動作します。
