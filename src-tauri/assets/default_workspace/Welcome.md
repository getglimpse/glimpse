# Welcome to Glimpse

Glimpse is a keyboard-first local launcher for quickly finding, previewing, and opening local knowledge.

Use it for notes, project documents, snippets, bookmarks, command references, Internal Pages, and trusted plugin tools.

## What Glimpse Indexes

- Markdown files with live preview
- Text, image, and raw files
- Glimpse JSON indexes saved as `.gjson`
- Metadata such as `tags`, `aliases`, `star`, `hidden`, and `open.*`
- Large documents, audio, video, PDF, and Office files as metadata-only entries
- Built-in Internal Pages and trusted plugin pages

Ordinary `.json` files are indexed as raw files. Use `.gjson` when you want one file to define multiple searchable Glimpse items.

## Start Here

1. Create or edit files in this workspace.
2. Search by title, body text, tag, alias, or metadata.
3. Select a result to preview it instantly.
4. Press `Ctrl + T` to keep a preview open as a tab.
5. Type `:help`, `:settings`, or `:plugin` to open built-in pages.

Open **Getting Started.md** next for a short walkthrough.
